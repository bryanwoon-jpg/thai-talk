# Lesson topics

The daily lesson task takes the first unticked topic, writes it as a new lesson in `js/content.js`, then ticks it off with the date and lesson id. Reorder, add or delete lines any time: the task always follows this list.

Format: `- [ ] tutor | topic | what the learner practises`
Tutors: `noi` (food), `ton` (getting around), `lek` (shopping and errands), `fon` (friends and work).
